# 视觉升级计划

## 问题背景

当前招新网站已经完成内容分页、图片 WebP 化和 GitHub Pages 发布，但整体视觉仍偏平：首屏与内页之间的品牌语言不够统一，导航、分页卡片和正文区域缺少更明确的层次与动效反馈。

## 修改目标

在不改动 `recruitement.md` 对应文案、页面顺序和图片素材的前提下，增强科技感、品牌识别度和阅读节奏。重点包括：首屏视觉冲击、页间背景层次、标题装饰、图片卡片质感、导航状态和轻量滚动动效。

## 实施范围

- 主要修改 `deck.css` 的最终覆盖规则，复用现有 HTML 结构和素材。
- 不新增文案，不替换用户提供的图片，不调整章节顺序。
- 保持移动端单列阅读、滚动分页和首屏防闪烁逻辑。
- 通过 CSS 伪元素、渐变、边框、阴影和已有 `reveal` 类完成视觉升级，避免引入额外依赖。

## 验证方式

- `git diff --check` 检查样式文件格式。
- 检查 HTML 中引用的图片路径均存在。
- 运行本地静态服务后确认页面能正常加载、无横向溢出、分页滚动和导航仍可用。
- 提交并推送到 GitHub Pages 后确认线上入口返回成功。
