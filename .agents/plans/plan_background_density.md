# 背景编排与页面充实计划

## 问题背景

当前演示页已经完成 WebP 素材迁移和基础排版，但 RoboMaster 介绍中的战场俯视图仍处于该部分中间，且各页背景的分配缺少内容上的连续性。部分页面正文和图片区域仍偏松，影响信息密度与浏览节奏。

## 修改目标

1. 将战场俯视图移动到 RoboMaster 介绍部分的最后一页，作为该部分的收束页。
2. 按内容逻辑重新编排背景：赛场与战队内容使用对应的赛场/团队素材，技术部分按组织架构、机械、电控算法、软件和宣运内容分组，分享与资料部分保持独立的视觉节奏。
3. 增大正文可读字号、图片占用面积和页面有效内容区域；标题字号保持现有值不变。
4. 保持桌面端和移动端单页展示，不引入横向拖动或内容溢出。

## 涉及文件

- `script.js`：调整 RoboMaster 部分的分页计划，将空白战场图页放到该部分末尾。
- `deck.css`：增加最终背景编排覆盖规则，并微调正文、图片区域的密度；不修改标题字号。
- `index.html`：更新样式和脚本的缓存版本号，确保发布后加载本次编排。

## 潜在影响

- RoboMaster 部分页内顺序会变化，但该部分总页数和整套页码保持一致。
- 背景图会更少重复，部分页面的视觉焦点和图片尺寸会变化。

## 验证方式

1. 检查 RoboMaster 部分最后一页使用 `rmuc_2026_field_top_view.webp`，中间页不再使用该图。
2. 检查总页数、首页页码和各区段顺序。
3. 在 1440×900 与 390×844 视口检查所有页面无横向/纵向溢出，所有图片加载完成。
4. 执行 `git diff --check`，提交并发布到 GitHub Pages 后检查线上响应。
