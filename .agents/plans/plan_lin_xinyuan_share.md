# 林新源老队员分享排版计划

## 目标

在现有“老队员分享”之后新增林新源的分享内容，完整保留用户提供的口述文案，并按演示页节奏拆分，避免长段文字挤在同一页。

## 排版策略

- 新增独立的分享段落，沿用现有深色、红蓝强调和滚动分页视觉。
- 依据内容主题拆分为连续页面：个人开场、零基础培训、进入车组、学业兼顾、社团氛围、合作关系、选择与收获、个人成长经历、结尾召集。
- 用户标注“培训计划截图”“开发图片”“飞书图片”“挂群聊”的页面保留右半边媒体预留区，不新增或猜测图片素材。
- 文字只使用用户本次提供的内容；用于导航和布局的标题仅使用“林新源”和现有栏目语义。

## 涉及文件

- `index.html`：新增林新源分享段落及完整文案。
- `deck.css`：新增该段落的桌面双栏、图片预留和移动端单栏样式。
- `index.html` 的样式缓存版本号递增，确保 GitHub Pages 获取新样式。

## 验证

- 检查 HTML/CSS 修改无格式错误，脚本语法不受影响。
- 检查新增页面顺序、文案完整性和媒体预留区位置。
- 提交并推送到 GitHub Pages，确认工作区干净。
